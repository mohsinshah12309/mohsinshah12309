## 🚀 Featured Projects

### 🔐 SecureChat — Real-Time Chat App with End-to-End Encryption

<img align="right" src="https://github-readme-stats.vercel.app/api/pin/?username=mohsinshah12309&repo=chat-app&theme=nord&border_color=7dd3fc&title_color=7dd3fc&text_color=c9d1d9&bg_color=0d1117" alt="SecureChat repo card"/>

Client-side E2E encrypted messaging app using ECDH (P-256) keypairs and AES-256-GCM shared secrets, real-time multi-room chat via Socket.io, message reactions, reply-threading, and voice notes — deployed on a split Vercel/Render/MongoDB Atlas architecture.

| Layer | Technology |
|---|---|
| Frontend | React.js (Vite) |
| Backend | Node.js, Express.js |
| Real-Time | Socket.io |
| Security | JWT, bcrypt, Web Crypto API (ECDH P-256, AES-256-GCM) |
| Database | MongoDB |
| Deployment | Vercel, Render |

🔗 [Live Demo](https://chat-app-iota-lemon-77.vercel.app/) &nbsp;|&nbsp; 💻 [Code](https://github.com/mohsinshah12309/chat-app)
